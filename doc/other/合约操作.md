# 合约交易操作系统

> **核心理念**：盘前制定计划，盘中只执行系统。靠重复执行正期望策略赚钱，不靠单笔预测。
>
> **交易的本质是等**：只做看得懂的行情，等冲动消退、逻辑闭环，能坦然接受任何结果。不怕空仓，只怕做错。

---

## 每日流程

### 开仓前（前 30 分钟）

- [ ] 查看 BTC/ETH 4H 趋势，确定方向偏好
- [ ] 标注关键支撑/压力位
- [ ] 写下今日计划（最多 3 个潜在机会）
- [ ] 确认可用资金和已用风险额度

### 开仓中

- [ ] 只做执行，不做判断——严格执行开仓前计划
- [ ] 每笔开仓过自检清单（3.2）
- [ ] 开仓后**立即挂止损单**
- [ ] 记录每笔交易的入场理由和心理状态
- [ ] 日亏达 500U 立即停手

### 平仓后（后 15 分钟）

- [ ] 评估是否严格执行了系统
- [ ] 标记违规交易，分析原因

## 开仓自检清单（全部满足才可入场）

**方向与结构：**

- [ ] 4H 方向明确，当前顺着 4H 方向
- [ ] 1H 结构健康，高低点未被破坏
- [ ] 15M 在关键位置出现合理入场结构（突破已确认、非假突破）

**风险控制：**

- [ ] 止损位置明确（支撑/压力位 + 4H K线）
- [ ] 止损金额 ≤ 300U，止损幅度符合币种标准（主流币 ≤ 2.5%，Meme 币 ≤ 15%）
- [ ] 盈亏比 ≥ 1:2
- [ ] 当日亏损未达 500U，未连亏 3 单
- [ ] 避开资金费率结算前后 15 分钟

**心理状态：**

- [ ] 在执行系统，不是预测市场
- [ ] 不是因刚亏损想加码
- [ ] 这单错了能平静接受

> 如果这笔交易必须靠"希望"才能成立，那么不交易。没有机会时，空仓本身就是最好的交易。

## 一、资金管理

### 1.1 资金拆分

总资金三等分，独立运作、互不干扰：

| 资金池 | 用途   | 单笔风险上限   |
|-----|------|----------|
| 1/3 | 日内短线 | ≤ 300U   |
| 1/3 | 波段趋势 | ≤ 300U   |
| 1/3 | 备用容错 | **不可动用** |

### 1.2 仓位管理

**默认小单试错，重仓只在极端机会。**

| 阶段   | 仓位       | 条件            | 操作         |
|------|----------|---------------|------------|
| 试错仓  | ≤ 本金 20% | 出现入场信号        | 小仓试探方向     |
| 确认仓  | +30%     | 趋势确认、浮盈 > 止损额 | 顺势加仓       |
| 盈利加仓 | 用浮盈      | 浮盈持续扩大        | **本金永远不动** |
| 移动止损 | —        | 每次加仓后         | 止损上移至成本价上方 |

**重仓例外**：仅当 4H+1H+15M 三重共振、盈亏比 ≥ 1:3、当日无亏损时允许，止损仍 ≤ 500U。

### 1.3 风控铁律

| 规则     | 标准                 | 备注               |
|--------|--------------------|------------------|
| 单笔最大亏损 | **≤ 300U**         | 超过不入场，无例外        |
| 单日最大亏损 | **≤ 500U**         | 达到即停手            |
| 连续亏损熔断 | **连亏 3 单**         | 当日强制休息           |
| 仓位计算   | 允许亏损 ÷ 止损距离 = 仓位上限 | **从风险倒推，不从杠杆正推** |

## 二、交易系统

| 时间（UTC+8）         | 事件         | 操作要求             |
|-------------------|------------|------------------|
| 08:00             | 亚洲早盘       | 流动性回升，观察         |
| 10:00-14:00       | 🟢 黄金时段    | 历史最佳盈利时段，主力作战    |
| 15:00-16:00       | 欧洲早盘       | 波动加大，谨慎          |
| 20:00-22:00       | 🟢 白银时段    | 欧美盘重叠，可操作        |
| 21:30/22:30       | 美股开盘       | 注意对币圈的联动影响       |
| 23:00-08:00       | ⛔ **禁止开仓** | 只设止损，凌晨交易历史亏损严重  |
| 00:00/08:00/16:00 | ⚠️ 资金费率结算  | **前后 15 分钟禁止持仓** |

### 2.1 多周期分析框架

| 周期      | 作用  | 方法                   |
|---------|-----|----------------------|
| **4H**  | 定方向 | EMA 判多空，定了就守住，不来回切换  |
| **1H**  | 看结构 | 高低点是否健康？趋势还是震荡？      |
| **15M** | 找入场 | 关键位置是否出现合理结构？突破是否确认？ |

> 消除历史感觉，以当前趋势为准。只信趋势，不信记忆中的新高新低压力位。

### 2.2 入场方式

- **限价入场**，用划算的委托单下单
- 行情企稳后再入，**绝不插足快速波动**
- 急剧下跌时不搏反弹，必须等**连续两根绿线反转**
- 突破不追，等回踩确认

### 2.3 操作币种

| 币种类型               | 策略                         | 止损         |
|--------------------|----------------------------|------------|
| **主流币**（BTC/ETH 等） | 顺应趋势，高位做空，低位做多             | **≤ 2.5%** |
| **Meme 币**         | 只做多涨幅榜 Number 1 且当前涨幅已超70% | **≤ 15%**  |

> 不碰不在规则内的品种。Meme 币只做最强龙头，绝不碰跌幅版的品种。**不碰短时间内大涨的 Meme 币，容易接飞刀。**

### 2.4 多空策略

**做多：**

- 顺势：4H 多 + 1H 健康 + 15M 回踩支撑
- 逆势**禁止**，除非明确底部反转（连续两根绿线 + 放量）

**做空：**

- 顺势：4H 空（前一根是红线） + 1H 破位（前两根是红线且当前也是红线） + 15M 反弹受阻
- **不做空涨幅榜品种，不做空强势币**

### 2.5 止损纪律

**设置三要素：**

1. K线支撑/压力位（优先）
2. 可接受损失 ≤ 300U
3. 参考 4H K线

**执行：**

- 开仓时**同步挂止损单**，不依赖手动
- 到点严格止损，绝不犹豫，绝不后移止损线

**移动止盈止损的唯一使用场景：行情快速朝有利方向运动**

- 做多 + 快速上涨 → 设止盈止损（主流币止损 ≤ 2.5%，Meme 币止损 ≤ 15%）
- 做空 + 快速下跌 → 设止盈止损（主流币止损 ≤ 2.5%，Meme 币止损 ≤ 15%）

> 止损不是认输，是"这把牌不好，换下一把"。死扛扛的不是行情，是自尊心。扛过九次，第十次清零。

### 2.6 止盈策略

| 阶段     | 操作      | 目的    |
|--------|---------|-------|
| 浮盈 1倍  | 止损移至成本价 | 确保不亏  |
| 浮盈 2倍  | 平仓 2/3  | 锁定利润  |
| 剩余 1/3 | 移动止损跟踪  | 让利润奔跑 |

> 浮盈不是钱，提走的才是。

## 三、心态管理——"八不"铁律

| 铁律       | 核心要求            | 触发条件     |
|----------|-----------------|----------|
| **一不乱**  | 方向定了不改，信号不到不动   | 4H 方向未变  |
| **二不贪**  | 浮盈 2倍提 2/3      | 浮盈达 2R   |
| **三不扛**  | 止损到了就走          | 价格触及止损线  |
| **四不飘**  | 连赢 3 天后**休息三天** | 连续 3 天盈利 |
| **五不躁**  | 连亏 3 单**关机**    | 连续 3 笔亏损 |
| **六不疑**  | 规则定了就执行，盘中不怀疑   | 盘中犹豫时    |
| **七不贪多** | 只做熟悉品种          | 想开新标的时   |
| **八不赌**  | 拿利润赌，不拿本金赌      | 想加大仓位时   |
